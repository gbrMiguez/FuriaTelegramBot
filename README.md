# 🐆 FURIA Telegram Bot

Um bot do Telegram que fornece informações sobre a FURIA Esports, uma das maiores organizações de esports do Brasil.

## 📝 Descrição

Este bot foi desenvolvido para fornecer aos fãs da FURIA acesso rápido e fácil a informações sobre a organização, incluindo:
- História da organização
- Ranking atual
- Elenco de CS
- Influenciadores
- Redes sociais
- E muito mais!

O bot suporta comandos em português e inglês, tornando-o acessível para fãs de todo o mundo.

## 🚀 Funcionalidades

- Comandos em português e inglês
- Informações atualizadas sobre a FURIA
- Respostas instantâneas
- Interface amigável
- Mais de 30 comandos diferentes

## 💻 Tecnologias Utilizadas

- Python 3.x
- python-telegram-bot (v22.0)
- Biblioteca asyncio

## 📋 Pré-requisitos

- Python 3.6 ou superior
- pip (gerenciador de pacotes Python)
- Token do Bot do Telegram

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/furia-telegram-bot.git
cd furia-telegram-bot
```

2. Instale as dependências:
```bash
pip install python-telegram-bot
```

3. Configure o token do bot:
Substitua `"SEU_TOKEN_AQUI"` no arquivo `bot.py` pelo token fornecido pelo @BotFather no Telegram.

4. Execute o bot:
```bash
python bot.py
```

## 📌 Comandos Disponíveis

### Comandos em Português
- `/start` - Inicia o bot
- `/help` - Mostra ajuda
- `/perguntas` - Lista todos os comandos disponíveis
- `/historiafuria` - História da FURIA
- `/rankingfuria` - Ranking atual
- `/elencoscfuria` - Elenco atual de CS
- E muitos outros!

### Commands in English
- `/start` - Start the bot
- `/help` - Show help
- `/furiahistory` - FURIA's history
- `/furiaranking` - Current ranking
- `/furiaroster` - Current CS roster
- And many more!
