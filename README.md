# FuriaTelegramBot
Este bot foi desenvolvido para fornecer aos fãs da FURIA acesso rápido e fácil a informações sobre a organização, incluindo: - História da organização - Ranking atual - Elenco de CS - Influenciadores - Redes sociais - E muito mais!  O bot suporta comandos em português e inglês, tornando-o acessível para fãs de todo o mundo.
